# Bundled SDK

The Host bundle includes the implementation of @software-factory/runtime-sdk 0.3.0
from the user-supplied software-factory-runtime-sdk-0.3.0.tgz, retained under vendor/ in the source project.
The SDK manifest does not declare a license; no additional license is asserted here.
DSH, Cordis and the settings form's React runtime are supplied by the host rather than bundled.

The document-split icon is original artwork created for this plugin.
